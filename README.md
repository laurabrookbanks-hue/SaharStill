# SaharStill

SaharStill is a project management tool.

## How to Create a Project

Follow these steps to create a new project:

1. **Clone the repository**
   ```bash
   git clone https://github.com/laurabrookbanks-hue/SaharStill.git
   cd SaharStill
   ```

2. **Set up your project**
   - Create a new directory for your project files.
   - Add your project configuration (e.g., a `config.json` or similar settings file).

3. **Initialize the project**
   - Define your project name, description, and any relevant metadata.
   - Add your project's source files to the repository.

4. **Commit and push**
   ```bash
   git add .
   git commit -m "Initialize new project"
   git push origin main
   ```

5. **Share your project**
   - Open a pull request or invite collaborators to contribute.
